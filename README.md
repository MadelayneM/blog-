# 🧸 Pequenas Memórias

**Um mundo de descobertas e carinho.**

O **Pequenas Memórias** é um projeto de blog desenvolvido para registrar e organizar fotografias, vídeos e lembranças especiais da infância.

O projeto foi criado com uma proposta visual delicada e acolhedora, utilizando tons de azul-marinho, azul-claro e creme, além de elementos decorativos inspirados em ursinhos e álbuns de recordações.

## ✨ Funcionalidades

- Página inicial com apresentação do projeto.
- Seção sobre o pequeno Bento.
- Álbum de momentos especiais.
- Página de pequenas descobertas.
- Página dedicada a recordações de carinho.
- Galeria com fotografias e vídeos.
- Visualização ampliada das fotografias.
- Navegação entre imagens e filtros por categoria.

## 📂 Estrutura do projeto

```text
blog/
│
├── index.html
├── momentos.html
├── descobertas.html
├── carinho.html
├── galeria.html
│
├── style.css
├── script.js
│
└── Blog-Imagens/
    ├── Fotografias
    └── Vídeos
```

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura das páginas.
- CSS3 — estilização e responsividade.
- JavaScript — interatividade e navegação da galeria.

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html`.
4. Execute utilizando a extensão Live Server.

## 🎨 Identidade visual

A identidade visual foi desenvolvida com uma proposta delicada, utilizando:

- Azul-marinho.
- Azul-claro.
- Creme.
- Elementos decorativos de ursinhos.
- Estilo de álbum de fotografias.

## 💙 Objetivo

Criar um espaço digital para preservar lembranças, registrar descobertas e guardar momentos especiais da infância.
